Controls & rules

Keyboard: arrows = D-pad · X = B (jump) · Z = A (spin jump) · S = Y (run) · A = X · Q/E = L/R · Enter = Start · V = Select. Gamepads work too; remap in the emulator's controller menu.

Race: when the countdown hits GO, everyone's game resets at the same moment and your save RAM is wiped, so it's a fresh file for all. First to beat Bowser wins — the finish is detected automatically when the ending starts. Other racers appear as ghosts when you're in the same room of the same level. Save states and fast-forward are turned off during the race.
